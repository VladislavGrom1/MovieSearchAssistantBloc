# Глоссарий

Термины продукта и кода. В issue, тестах, ADR и комментариях используем слово из заголовка, а не синоним.

## Продукт

### AI-вкладка
Второй таб `HomeScreen` (`lib/presentation/pages/home_screen.dart`), роут `AiFilmsWrapperRoute` → `AiFilmsRoute`. Экран подбора фильмов по свободному описанию.

_Не говорить:_ «чат», «ассистент». Ассистент — это всё приложение.

### AI-запрос (`query`)
Свободный текст пользователя на русском: настроение, сюжет, жанр. До 200 символов, обрезается по краям перед отправкой. Пустой запрос не отправляется.

### AI-рекомендация (`AiFilmRecommendation`)
Пара «фильм + описание»: `FilmEntity film` и `String description`. Живёт только в памяти AI-вкладки.

_Не путать:_ с `FilmEntity`. Рекомендация не сохраняется в Hive, не попадает в коллекции и не переживает перезапуск приложения.

### Описание (`description`, в API — `reason`)
Русское описание сюжета фильма с Кинопоиска: 1–3 предложения. Показывается под постером в карточке результата.

_Не говорить:_ «обоснование», «почему выбрали», «причина». Модель не объясняет выбор — она отдаёт описание фильма.

### Карточка результата (`AiFilmResultCard`)
Виджет результата на AI-вкладке: постер по центру, рейтинг-бейдж, название, описание с обрезкой и раскрытием. Тап по карточке открывает экран деталей фильма.

### Постер (`FilmPosterImage`)
Картинка фильма со скруглением 16 и бейджем рейтинга. Базовый размер — 100×140; на AI-вкладке — 140×200.

## Состояния AI-вкладки

### Пустой результат (empty)
Сервер ответил `200` с `movies: []`. Отдельное состояние со своим текстом и кнопкой «Повторить».

_Не путать:_ с ошибкой. Пустой результат — валидный ответ, ошибка — нет.

### Ошибка подбора (failure)
Запрос не удался: сеть, таймаут, `400/404/405/500/502`. Показывается компактный блок с сообщением и кнопкой «Повторить».

## Данные

### Фильм (`FilmEntity`)
Существующая доменная сущность фильма (`lib/domain/entities/film_entity.dart`), ~50 nullable-полей. Из ответа AI-API заполняются только `kinopoiskId`, `nameOriginal`, `year`, `posterUrl`, `posterUrlPreview`, `ratingKinopoisk`.

### Экран деталей (`FilmInformationScreen`)
Существующий экран `FilmInformationRoute`. Открывается по `filmId` + `filmName`; описание из AI-ответа туда не передаётся.
