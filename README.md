## 🎬О проекте

**Movie Search Assistant Bloc** — это мобильное приложение, разработанное на Flutter, которое позволяет пользователям искать фильмы, подбирать их с помощью AI-ассистента, просматривать подробную информацию о фильмах и создавать личные коллекции. 

**Примечание:**
**Movie Search Assistant Bloc** является переосмыслением мобильного приложения [Movie Search Assistant](https://github.com/VladislavGrom1/MovieSearchAssistant). Проект разрабатывался для освоения архитектурного подхода Clean Architecture Bloc и расширения функциональных возможностей проекта.

Ключевые нововведения по сравнению с версией проекта [Movie Search Assistant](https://github.com/VladislavGrom1/MovieSearchAssistant):

- Новая архитектура и применение `flutter_bloc` для реализации State-Management
- `AI-Ассистент` для подбора фильмов по текстовому описанию и лента сохранённых AI-поисков
- Режим `«Без сохранённых фильмов»`: AI не рекомендует фильмы, которые уже есть в библиотеке
- Возможность создавать собственные `коллекции`
- Сохранение фильмов в несколько `коллекций` одновременно
- Возможность устанавливать `отзыв` и `личный рейтинг` сохранённым фильмам
- `Индикатор`, сообщающий пользователю, что фильм уже сохранён в одну из `коллекций`
- Похожие фильмы и обложки коллекций
- Экспорт/импорт сохранённых данных в формате `.zip` и отправка библиотеки через системное меню
- Доработанная система кэширования изображений и очистки `кэша`
- Счётчики занятой памяти: размер `кэша` и `библиотеки` в профиле
- Определение доступности сети по ответу API, а не только по наличию Wi-Fi или мобильной сети
- Обновлённый `UI/UX` для более приятного опыта использования приложения
- Публикация приложения в `RuStore`

## 🎬Основные возможности

- 🔍 Поиск фильмов по ключевым словам
- 🤖 AI-подбор фильмов по свободному описанию (сюжет, настроение, компания)
- 🕘 История AI-поисков: сохранённые сессии и лента рекомендаций

- 🎞️ Похожие фильмы на экране фильма
- ❤️ Создание, переименование и удаление личных коллекций
- 🎨 Обложки коллекций: выбор изображения из галереи
- 🎬 Локальное сохранение фильмов
- 🖼️ Кэширование постеров и изображений фильмов с возможностью очистки кэша
- 💾 Сохранение пользовательского рейтинга и отзыва к фильмам
- 📈 Счётчики памяти: размер кэша и библиотеки в профиле
- 🔑 2 плана работы приложения: с общим или личным API Key
- 📤 Поделиться библиотекой через системное меню
- 🔄 Импорт и экспорт коллекций (.zip)
- 📡 Отслеживание состояния интернет-соединения и работа без сети с уже сохранёнными данными

**Ключевые технологии и пакеты:**

- `flutter_bloc` — управление состоянием (BLoC/Cubit)
- `get_it` — Dependency Injection
- `auto_route` — декларативная навигация
- `dio` — HTTP-клиент для работы с API
- `hive` — локальное key-value хранилище (библиотека, AI-сессии)
- `connectivity_plus` — отслеживание состояния сети
- `cached_network_image` / `flutter_cache_manager` — кэширование постеров
- `skeletonizer` — скелетоны загрузки
- `share_plus` / `file_picker` — отправка и импорт библиотеки
- `image_picker` / `flutter_image_compress` — обложки коллекций
- `package_info_plus` — версия приложения в профиле
- `media_store_plus` / `path_provider` — работа с файловой системой при экспорте/импорте
- ZIP-сервис на основе собственной обёртки для экспорта/импорта библиотеки
- AI-подбор и прокси к API — собственные сервисы на Cloudflare Workers

## 🎬AI-Ассистент

AI-Ассистент открывается с экрана поиска и помогает найти фильм, когда не хочется перебирать жанры и годы:

- Опишите, что хочется посмотреть: сюжет, настроение, компанию — запрос до 200 символов
- Ассистент вернёт подборку фильмов с постерами, годом и жанрами
- Лента поисков сохраняется после перезапуска приложения: можно вернуться к прошлым запросам, развернуть их и удалить ненужные
- Режим «Без сохранённых фильмов» (переключатель «Не рекомендовать сохранённые фильмы») исключает из подборки фильмы, которые уже есть в библиотеке
- Если сервис не ответил, запрос можно повторить, не вводя текст заново

## 🎬API

Данные о фильмах приложение получает от сервиса Kinopoisk API Unofficial через собственный прокси на Cloudflare Workers:

👉 https://kinopoiskapiunofficial.tech

👉 По умолчанию в приложении установлен `Стандартный план` работы приложения: не требуется ввод API Key, неограниченное количество запросов в сутки, возможны задержки при получении данных от сервера при больших нагрузках

⚠️ Для перехода на `Индивидуальный план` работы приложения Movie Search Assistant необходимо получить API-ключ и ввести его в мобильном приложении:

1. Зарегистрируйтесь на сервисе https://kinopoiskapiunofficial.tech и в профиле получите свой API-ключ
2. Введите API-ключ в Профиле — он сохраняется локально на устройстве
3. Используйте приложение с индивидуальным лимитом запросов в сутки и без задержек получения данных от сервера

**Важно:**
- Бесплатный лимит — 500 запросов в сутки
- Требуется интернет-соединение для поиска и AI-подбора

## 🎬Профиль и память

В профиле видно, сколько места занимают данные приложения:

- `Размер кэша` — постеры и изображения, которые можно удалить без потери библиотеки
- `Библиотека фильмов` — коллекции, сохранённые фильмы, отзывы и рейтинги

`Очистить кэш` удаляет только кэш изображений: библиотека, AI-сессии и настройки остаются на месте. `Очистить библиотеку` удаляет коллекции и сохранённые фильмы — действие требует подтверждения.

## 🎬Экспорт / Импорт данных

Приложение поддерживает:

- Экспорт всей библиотеки (коллекции, фильмы, отзывы, рейтинги, изображения) в `.zip`
- Импорт данных обратно в приложение из ранее выгруженного `.zip`
- Отправку библиотеки через системное меню — «Поделиться библиотекой»
- Очистку локального кэша изображений и полную очистку библиотеки

AI-сессии и их постеры в экспорт не входят: это отдельная история, которая не относится к библиотеке.

Это позволяет сохранять и переносить данные между устройствами, а также не терять коллекции при переходе с предыдущей версии приложения.
